# Apple HIG HTML-шаблон подписки для 3x-ui

<!-- Build Timestamp: 18:45.31.10.2026 -->

Премиальный, полностью адаптивный HTML-шаблон страницы подписки для панели **3x-ui** (MHSanaei и форки), созданный в строгом соответствии с принципами **Apple Human Interface Guidelines (Apple HIG)**.

---

## ✨ Ключевые возможности

1. **Дизайн в стиле Apple (iOS 18 / macOS Sequoia)**:
   - Эстетика **Liquid Glass**: полупрозрачные панели с эффектом матового стекла (`backdrop-filter: blur(24px) saturate(190%)`).
   - Истинный черный фон (OLED Black) для тёмной темы и мягкий `systemGroupedBackground` (`#F2F2F7`) для светлой темы.
   - **Авто-тема по умолчанию**: загружает светлую или тёмную тему автоматически в соответствии с системной темой устройства (`prefers-color-scheme`).
   - Фирменный лаконичный переключатель **День / Ночь** для ручного переключения.
   - Плавные микро-анимации, тактильный отклик при нажатиях (`scale(0.98)`).
   - Сенсорные зоны (Touch Targets) не менее **44x44px**.
   - Фирменная иконка-фавикон (синий защитный щит со стрелкой).

2. **Точный статус подписки и конфиденциальность**:
   - **Строгая проверка валидности**: если подписка отключена, истекла по времени или исчерпан лимит трафика — немедленно выводится статус **«Не активна»**, **«Срок истек»** или **«Лимит исчерпан»** с красным бейджем и предупреждающим индикатором.
   - **Скрытие внутренних идентификаторов**: имя клиента (`remark`), email и UUID панели скрыты. Отображается только нейтральный заголовок **«VPN сервис»** / **«VPN Service»**.
   - Полная автономность (Zero 3rd-party CDN): все скрипты, SVG-иконки и движок генерации QR-кодов встроены непосредственно в один файл.

3. **Центрированный QR-код и удобные кнопки**:
   - QR-код для подключения сразу виден по центру экрана на чистой контрастной карточке с мягкой тенью и скруглениями.
   - Под QR-кодом расположена крупная кнопка быстрого копирования ссылки на подписку.
   - Заметные, сбалансированные кнопки быстрого доступа: **«Ссылка SUB»** (копирование) и **«Конфиг JSON»** (открытие / скачивание JSON-профиля).

4. **Двуязычный интерфейс (RU / EU)**:
   - Переключатель языка **RU | EU** в верхней панели навигации с мгновенной сменой всех текстовых элементов без перезагрузки страницы.
   - Выбор сохраняется в `localStorage`.

5. **Поле «Был в сети» (Last online)**:
   - Отображение точного времени последней активности клиента на основе метрики панели `lastOnline` (например, `31.10.2026, 17:53`).
   - При отсутствии подключений выводится «Никогда» / «Never».

6. **Виджеты трафика и активности**:
   - **Activity Ring**: круговой индикатор расхода трафика с динамическим изменением цвета (Apple Fitness style: Синий → Оранжевый → Красный при >90% или неактивной подписке).
   - Карточки статистики: Использовано, Всего, Загрузка, Отдача, Срок действия и Остаток квоты.
   - Баннер системных оповещений (если в 3x-ui задан `announce`).

7. **Каталог приложений по платформам (iOS, Android, Windows, macOS)**:
   - Вкладки выбора операционной системы с автоопределением устройства пользователя при первой загрузке.
   - Встроены **оригинальные иконки из стандартного шаблона 3x-ui** (Shadowrocket, Streisand, V2Box, Sing-box, Happ, V2RayNG, V2RayTun, Incy, Clash).
   - Для каждого приложения доступен 1-клик импорт профиля по схеме deep link (`shadowrocket://`, `v2box://`, `sing-box://`, `v2rayng://`, `happ://`, `clash://`), а также прямая ссылка на установку.

8. **Список доступных серверов**:
   - Чистый единый список всех серверов подписки без лишних протокольных групп.
   - Автоматическое определение флага страны (🇳🇱, 🇩🇪, 🇺🇸, 🇬🇧, 🇫🇮, 🇫🇷, 🇹🇷, 🇸🇬, 🇯🇵) из названия локации.
   - Живой поиск по названию локации или типу протокола.
   - Кнопка быстрого копирования индивидуального ключа сервера и просмотр индивидуального QR-кода в модальном окне.

## 🚀 Установка на сервер с 3x-ui

### 1. Скопировать шаблон на сервер:
```bash
# Создать директорию для кастомного шаблона
mkdir -p /etc/x-ui/sub_templates/apple

# Скопировать index.html и sub.html
cp assets/sub-template/index.html /etc/x-ui/sub_templates/apple/index.html
ln -sf /etc/x-ui/sub_templates/apple/index.html /etc/x-ui/sub_templates/apple/sub.html
```

### 2. Активировать шаблон в настройках 3x-ui:
Через веб-панель:
> **Настройки панели** ➔ **Настройки подписки** ➔ **Каталог тем подписки** (`Sub Theme Directory`) ➔ указать `/etc/x-ui/sub_templates/apple` ➔ нажать **Сохранить** и перезапустить панель.

Либо напрямую через SQLite (мгновенно):
```bash
sqlite3 /etc/x-ui/x-ui.db "DELETE FROM settings WHERE key = 'subThemeDir'; INSERT INTO settings (key, value) VALUES ('subThemeDir', '/etc/x-ui/sub_templates/apple');"
systemctl restart x-ui
```

## 🛠 Локальное тестирование шаблона

Шаблон содержит встроенный **Standalone Preview Mode**. Вы можете просто открыть файл `index.html` в любом современном браузере:
```bash
open assets/sub-template/index.html
```
Если страница открыта напрямую (без Go-сервера 3x-ui), шаблон автоматически активирует реалистичные демонстрационные данные, позволяя протестировать Activity Ring, темы оформления, язык RU/EU, вкладки приложений, поиск серверов и генерацию QR-кодов.
